# Mahak Rawat — Portfolio Website

A responsive, dark-themed personal portfolio starter for showcasing AI experiments, data analytics projects, and web development work.

## Preview locally
1. Download or extract this project.
2. Open `index.html` in a browser.

No build tools or installation are required.

## Personalise before publishing
- Confirm the display name and bio in `index.html`.
- Replace the sample project concepts with your **actual completed projects**.
- Update each project title, description, technology tags, and GitHub repository link.
- Add screenshots or demo links when available.
- Remove any skill you have not started learning yet.
- Add a professional contact email only if you want it public.

The AI Learning Lab and Data Analysis Dashboard cards are starter ideas/placeholders, not completed-work claims.

## Publish with GitHub Pages
1. Sign in to GitHub as `mahakrwt22-arch`.
2. Create a new **public** repository named exactly `mahakrwt22-arch.github.io`.
3. Keep it empty (do not add a README, license, or `.gitignore` during creation).
4. On the new repository page, choose **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder (upload the files themselves, not the containing folder).
6. Enter a commit message such as `Add personal portfolio website`, then click **Commit changes**.
7. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
8. Wait a few minutes. Your site should appear at:
   `https://mahakrwt22-arch.github.io`

## Updating your portfolio
Edit the files locally or use GitHub's pencil icon to edit them online, then commit the changes. GitHub Pages republishes the site automatically.
